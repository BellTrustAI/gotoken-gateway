API 接入说明

Gateway 提供兼容 OpenAI API 格式的接口，支持 Chat Completions、Models List 和 Health Check。

Base URL http://your-host:8789
认证方式 Authorization: Bearer <token>
获取模型列表 curl -H "Authorization: Bearer <token>" {base}/models
Chat Completions curl -X POST {base}/chat/completions \ -H "Authorization: Bearer <token>" \ -H "Content-Type: application/json" \ -d '{"model":"<model-id>","messages":[{"role":"user","content":"hello"}]}'
健康检查（无需认证） curl {base}/healthz
One API 配置

在 One API 中添加自定义渠道：类型选择 OpenAI，Base URL 填写上述地址，密钥填写创建的 API Token。
